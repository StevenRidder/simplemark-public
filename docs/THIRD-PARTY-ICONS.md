# Third-party icons

SimpleMark uses a small, local subset of the official outline icons from
[Tabler Icons](https://tabler.io/icons). The selected SVG paths are stored in
`src/app/ui/tabler-icons.ts`; the app makes no network request for icons and
does not ship the full icon package.

Tabler Icons are copyright Paweł Kuna and contributors and distributed under
the MIT License: <https://github.com/tabler/tabler-icons/blob/main/LICENSE>.

New product icons must come from this same official Tabler set. Do not add a
second icon family or draw one-off replacements.
